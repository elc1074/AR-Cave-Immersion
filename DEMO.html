🚀 Quick Start (3 passos)

  1. Instalar dependências
    npm install
  2. Rodar servidor
    npm run dev
  3. Abrir aplicação
    https://localhost:5174/

🌐 URLs Importantes

Aplicação (com autenticação):

https://localhost:5174/

Gerador de QR Code (para testes):

https://localhost:5174/qr-generator.html

QR Code pré-gerado (PNG):

https://localhost:5174/public/qr-auth-test.png

✨ Formatos de QR Code Suportados

1. Texto simples:

meu-token-123

2. JSON com token:

{"token": "ar-cave-auth-2025"}

3. JSON completo:

{"token": "auth", "user": "kaio", "role": "admin"}
